# Portfolio Website 🌐

Hi! This is my personal portfolio website showcasing my projects, skills, and experience as a web developer.

## Features ✨

* Projects showcase with live demos
* Contact section to get in touch

## Built With 🛠️

React.js, Tailwind CSS, Vite, Framer Motion, ShadCN UI

## Run Locally 🚀

```bash
git clone https://github.com/TariqCO/MyPortfolio.git
cd portfolio-website
npm install
npm run dev
```
